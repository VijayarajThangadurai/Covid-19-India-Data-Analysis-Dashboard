## 📌 Project Overview

This Tableau dashboard provides a comprehensive analysis of the Covid-19 pandemic in India using interactive visualizations and analytical insights. The dashboard helps users understand the impact of Covid-19 across different states, age groups, genders, testing facilities, and vaccination progress.

The project transforms raw Covid-19 data into meaningful visual stories that support better understanding and decision-making.

---

# 🎯 Objectives

* Analyze Covid-19 cases, recoveries, and deaths across India.
* Visualize state-wise pandemic statistics.
* Understand demographic distribution based on age and gender.
* Compare testing and healthcare infrastructure among states.
* Track vaccination progress through first and second dose analysis.
* Build an interactive and user-friendly Tableau dashboard.

---

# 📊 Dashboard Features

## 1️⃣ Map: Total Deaths by State

* Displays state-wise Covid-19 death distribution on an India map.
* States are color-coded based on the severity of deaths.
* Helps identify the most affected regions.

## 2️⃣ Age Group Details

* Donut chart representing Covid-19 cases across different age groups.
* Provides demographic insights into affected populations.

## 3️⃣ Covid Cases from States

* Line chart comparing:

  * Confirmed Cases
  * Cured/Recovered Cases
  * Death Cases
* Shows the trend and growth of Covid-19 over time.

## 4️⃣ ICMR Testing Labs in Each State

* Bar chart displaying the number of ICMR-approved testing laboratories.
* Highlights healthcare and testing infrastructure availability.

## 5️⃣ Gender Without Missing Values

* Donut chart showing gender-wise distribution of Covid-19 cases.
* Compares male and female infection percentages.

## 6️⃣ Statewise Testing Details

* Comparative analysis of:

  * Total Samples Tested
  * Positive Cases
  * Negative Cases
* Helps evaluate testing performance across states.

## 7️⃣ First vs Second Dose Administered

* Visualization comparing first-dose and second-dose vaccinations.
* Tracks vaccination campaign progress in India.

# 📈 Key Insights

* Maharashtra reported one of the highest Covid-19 death counts.
* The 20–29 age group showed a significant percentage of cases.
* Male patients accounted for a larger proportion of infections.
* First-dose vaccination numbers were considerably higher than second-dose counts.
* States with better testing infrastructure conducted more tests overall.
